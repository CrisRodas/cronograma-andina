# Cronograma Proyecto SIU - Universidad Andina

Cronograma interactivo (Gantt, hitos, ruta crítica, swimlane por responsable y dependencias) del proyecto SIU Universidad Andina.

- Inicio: 02/11/2026
- Fin: 11/12/2026
- Duración planificada: 40 días calendario · 35 tareas

## Ver en línea

Publicado con GitHub Pages: el archivo `index.html` contiene toda la vista.

Los avances (% por tarea) se sincronizan en tiempo real vía Firebase. La edición requiere iniciar sesión; sin sesión, la vista es de solo lectura.
